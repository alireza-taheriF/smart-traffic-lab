# Benchmarks

Generated by `npm run report` from `results/*.json` (do not edit by hand).

* **Load** = vehicles/hour on each main entry (east/west); north/south entries get 65% of that.
* **Delay** = mean seconds a vehicle spends *stopped*, **including vehicles still waiting when the run ends** (no survivor bias).
* Both controllers see exactly the same random vehicles (paired comparison). 5 seeds (101-105, never used for tuning), 300 s warm-up + 1500 s measured.
* "Fixed" = the baseline that mimics common Iranian practice (fixed cycle, 35 s through / 12 s left arrow, countdown timers).
